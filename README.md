# pre-entrega-automation-testing-Marcos-Esquivel

Proposito de proyecto:
- se trata de un conjunto de pruebas automatizadas para la plataforma de pruebas SauceDemo (https://www.saucedemo.com), cubriendo flujos críticos como autenticación, gestión del inventario y carrito de compras.

Las tecnologías utilizadas son:

- Python (Lenguaje de programación base).
- Pytest (Framework de pruebas).
- Selenium WebDriver (Automatización del navegador).
- Webdriver Manager (Gestión automática de drivers).
- Pytest-HTML (Generación de reportes de ejecución en HTML).

para instalar las dependencias python y Node.js:

- Python: pip install (nombre_del_paquete)
- Node.js: npm install (nombre_del_paquete)

para ejecutar las pruebas:

- Para ejecucion estandar con Pytest (utilizando la configuracion definida en pytest.ini):
- pytest
